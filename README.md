## ⚙️ Быстрый гайд по установке

1. Откройте файл `cheats_list.txt` и выберите нужный софт под вашу версию игры.
2. Скачайте архив или `.jar` файл по ссылке из списка.
3. Откройте папку игры:
   * Нажмите `Win + R`, введите `%appdata%\.minecraft` и нажмите **Enter**.
4. Поместите файлы в соответствующую директорию:
   * Для модов — в папку `mods`.
   * Для версий клиентов — в папку `versions`.
5. Запустите лаунчер и выберите установленный профиль.

## ❓ Что делать, если ничего не работает? (Решение проблем)

Если игра крашится, не запускается или выдаёт ошибки:

> 💡 **Совет:** В 90% случаев проблемы вызваны неправильной версией Java или отсутствием системных библиотек.

### 🛠 Полезные ссылки и компоненты:

* ☕ **Обновление Java Runtime:**
  * [Скачать Java 8 (для старых версий 1.12.2 и ниже)](https://www.java.com/en/download/)
  * [Скачать Java 17 / 21 (для новых версий 1.16.5+)](https://adoptium.net/)
* 📦 **Системные библиотеки Windows:**
  * [Набор Microsoft Visual C++ Redistributable](https://learn.microsoft.com/ru-ru/cpp/windows/latest-supported-vc-redist) *(нужен для корректной работы инжекторов и библиотек)*
* 🧩 **Загрузчики модов (Mod Loaders):**
  * [Официальный сайт Fabric](https://fabricmc.net/use/installer/)
  * [Официальный сайт Forge](https://files.minecraftforge.net/)

---

### ⚠️ Частые ошибки:

* **Краш с кодом 1:** Проверьте совместимость модов между собой и соответствие версии Java версии игры.
* **Антивирус блокирует файл:** Многие лаунчеры и инжекторы вызывают ложные срабатывания защитника Windows. Добавьте рабочую папку в исключения, если доверяете источнику.
* **Ошибка OpenGL / Драйверов:** Обновите драйверы видеокарты через официальное ПО производителя (NVIDIA / AMD / Intel).
